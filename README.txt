BANAMALI BOOK STORE — WEBSITE
==============================

Open index.html with Live Server in VS Code.

This is a dependency-light static website: HTML + CSS + vanilla JavaScript.
It includes:
- Responsive modern editorial design
- CSS 3D book scene with pointer interaction
- Scroll reveal animations
- Search and category filters
- Mobile navigation
- Google Maps search link
- Copy-location interaction

IMPORTANT CONTENT NOTE
The site uses the user-provided business facts:
- Established in 1937
- One of the oldest book stores in Jagatsinghpur
- Owner: Mr. Ramakanta Sahoo
- Jagatsinghpur, Odisha; near Court Chhak

The shelf section is intentionally presented as categories, NOT live inventory.
No unverified phone number, email, hours, prices, or stock have been invented.
